# DEC-005 — Lekka dokumentacja projektowa

## Status

accepted

## Data

2026-06-02

## Kontekst

Projekt jest prowadzony jednoosobowo, ale ma być rozwijany profesjonalnie i możliwy do kontynuacji po przerwach.

## Decyzja

Dokumentacja będzie lekka, modułowa i aktualizowana po sesjach pracy. Nie tworzymy dużego dokumentu strategicznego, tylko zestaw krótkich plików Markdown.

## Alternatywy

- brak dokumentacji,
- jeden duży dokument,
- rozbudowany system projektowy przed kodem.

## Uzasadnienie

Krótkie dokumenty pomagają podejmować decyzje, porządkować backlog i wracać do projektu bez przeciążenia.

## Konsekwencje

Po każdej większej sesji należy aktualizować changelog, backlog i decyzje, jeśli zaszły istotne zmiany.
