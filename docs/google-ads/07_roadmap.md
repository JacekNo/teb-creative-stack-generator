# 07 — Roadmap

## Etap 0 — przygotowanie danych

- Normalizacja kierunków.
- Normalizacja miast.
- Brand tokens.
- Mapowanie zdjęć.
- Wybór przypadków testowych.

## Etap 1 — MVP Google Ads

- 3 formaty.
- 3 brandy.
- Podgląd pojedynczej kreacji.
- Eksport PNG.
- Podstawowy walidator tekstu i zdjęć.

## Etap 2 — eksport masowy

- Import wielu rekordów.
- Eksport ZIP.
- Raport walidacji.
- Nazewnictwo plików.

## Etap 3 — kontrola jakości

- Warianty layoutu dla długich nazw.
- Focal point zdjęcia.
- Panel wyjątków.
- Statusy: OK / WARNING / ERROR.

## Etap 4 — social media

- Szablony social.
- Dane kampanijne.
- Przewagi, partnerzy, certyfikaty.
- Format 1200×1200, stories, reels cover, karuzele.
- Więcej wariantów copy.

## Etap 5 — integracja z PAW Generator

- Wspólna biblioteka assetów.
- Panel zarządzania zdjęciami.
- Statusy assetów.
- Docelowo backend i autoryzacja.
